# Remotion Reference Notes & Operational Playbook

This reference provides technical guidance on integrating and running Remotion within the `football-video-pipeline` orchestrator.

---

## 1. Core Composition Primitives

### `<Composition>` Registration
Every Remotion project defines compositions in its entry point (e.g. `src/Root.tsx` or `remotion/Root.tsx`):

```tsx
import { Composition } from "remotion";
import { FootballShort } from "./FootballShort";

export const RemotionRoot: React.FC = () => {
  return (
    <Composition
      id="FootballShort"
      component={FootballShort}
      durationInFrames={1140} // 38s @ 30fps
      fps={30}
      width={1080}
      height={1920}
      defaultProps={{
        scenes: [],
        fullScript: "",
        tickerText: "",
      }}
    />
  );
};
```

### `<Series>` for Sequential Scenes
When rendering sequential editorial scenes, `<Series>` automatically calculates the timeline offsets without manual frame addition:

```tsx
import { Series } from "remotion";

export const SceneTimeline: React.FC<{ scenes: SceneProps[] }> = ({ scenes }) => {
  return (
    <Series>
      {scenes.map((scene) => (
        <Series.Sequence
          key={scene.scene_id}
          durationInFrames={scene.durationInFrames}
        >
          <EditorialScene scene={scene} />
        </Series.Sequence>
      ))}
    </Series>
  );
};
```

### `<Sequence>` for Persistent HUD & Subtitles
For overlays that span the entire Short or have independent timing (such as the top channel bug, lower third, and rolling ticker), `<Sequence>` layers elements concurrently:

```tsx
import { Sequence } from "remotion";

export const VideoOverlay: React.FC<{ tickerText: string; totalFrames: number }> = ({
  tickerText,
  totalFrames,
}) => {
  return (
    <>
      <Sequence from={0} durationInFrames={totalFrames}>
        <ChannelBug />
        <RollingTicker text={tickerText} />
      </Sequence>
    </>
  );
};
```

## 2. Headless CLI Rendering from Python

The Python orchestrator invokes Remotion headlessly via subprocess using `npx remotion render`.

### Basic Command Structure
```bash
npx remotion render [composition-id] [output-file] --props=[path-or-json]
```

### Production Flags for Headless Reliability
- `--props=path/to/props.json`: Ingests the dynamic scene plan, audio paths, and text generated by Python.
- `--concurrency=4`: Optimizes multi-core rendering on consumer CPUs.
- `--gl=angle` (or `--gl=swiftshader`): Ensures reliable GPU/software rasterization on Windows without headless Chromium GPU crashes.
- `--log=warn`: Suppresses verbose frame progress logs to keep stdout clean.
- `--image-format=jpeg` (or `png`): Uses high-quality intermediate frames.

### Python Orchestrator Integration Pattern
```python
import json
import subprocess
from pathlib import Path

def render_remotion_composition(
    composition_id: str,
    props: dict,
    output_path: Path,
    remotion_dir: Path
) -> Path:
    props_file = remotion_dir / "temp_props.json"
    props_file.write_text(json.dumps(props, indent=2), encoding="utf-8")
    
    cmd = [
        "npx.cmd", "remotion", "render",
        composition_id,
        str(output_path.resolve()),
        f"--props={props_file.resolve()}",
        "--concurrency=4",
        "--log=warn",
        "--overwrite"
    ]
    
    res = subprocess.run(cmd, cwd=str(remotion_dir), capture_output=True, text=True, check=True)
    return output_path
```

## 3. Extracting Frame Stills & Storyboard Contact Sheets

Remotion supports instant still and multi-frame extraction without rendering the full video:

```bash
# Render a single still image at frame 45
npx remotion still FootballShort out/still_45.png --frame=45 --props=props.json

# Render keyframes across scenes for visual QA contact sheets
npx remotion render FootballShort out/storyboard_frames --frames=30,120,240,360,480,600,720 --image-format=png --props=props.json
```

This allows the automated QA Inspector to verify typography, safe-zone clearance, and image framing in under 5 seconds before initiating a full video render.
